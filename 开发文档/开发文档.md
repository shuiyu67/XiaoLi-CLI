## 1. 系统架构概述

### 1.1 三大协议支持

小狸 Pro-CLI 的工具系统支持三种协议：

| 协议 | 目录 | 说明 |
|------|------|------|
| **Plugin 协议** | `plugins/` | 小狸自有协议，简单易用 |
| **Skill 协议** | `skills/` | Agent Skills 开源协议，支持 Markdown 和 Python 格式 |
| **MCP 协议** | - | Model Context Protocol，Anthropic/OpenAI 标准 |

### 1.2 统一工具管理器

`unified_tool_manager.py` 协调三种协议，提供统一的工具调用接口：

```python
from unified_tool_manager import UnifiedToolManager

manager = UnifiedToolManager(cli_instance)
manager.initialize("plugins", "skills")

# Plugin 格式调用
result = manager.execute("file_manager", "read test.txt")

# MCP 格式调用
result = manager.mcp_call("file_manager", {"operation": "read", "path": "test.txt"})
```

### 1.3 路由策略

- 优先使用 Skill 协议（如果存在同名技能）
- 回退到 Plugin 协议
- 支持强制指定协议
- MCP 格式调用统一入口

## 3. Plugin协议开发

### 3.1 基本结构

```python
class Plugin:
    """插件描述"""
    
    def __init__(self):
        self.usage = "使用方法说明"
        self.cli = None
    
    def set_cli(self, cli):
        """设置CLI引用（可选）"""
        self.cli = cli
    
    def get_tool_info(self):
        """返回工具信息（必需）"""
        return {
            "name": "tool_name",
            "description": "工具描述",
            "keywords": ["关键词1", "关键词2"],
            "usage": self.usage
        }
    
    def get_mcp_definition(self):
        """返回MCP格式定义（可选）"""
        return {
            "name": "tool_name",
            "description": "工具描述",
            "inputSchema": {
                "type": "object",
                "properties": {
                    "operation": {"type": "string"},
                    "path": {"type": "string"}
                },
                "required": ["operation"]
            }
        }
    
    def convert_mcp_args(self, arguments):
        """转换MCP参数（可选）"""
        return f"{arguments.get('operation', '')} {arguments.get('path', '')}"
    
    def handle(self, args: str) -> str:
        """处理工具调用（必需）"""
        try:
            # 实现逻辑
            return "处理结果"
        except Exception as e:
            return f"错误: {str(e)}"
```

### 3.2 完整示例：文件管理器

```python
import os
from typing import Dict, Any, List

class Plugin:
    """文件管理器插件"""
    
    def __init__(self):
        self.usage = """文件管理器使用方法：
file_manager <操作> <参数>

操作类型:
- list <路径>           - 列出目录内容
- read <文件路径>       - 读取文件内容
- write <文件路径> -c "内容" - 写入文件
- delete <路径>         - 删除文件或目录
"""
        self.cli = None
    
    def set_cli(self, cli):
        self.cli = cli
    
    def get_tool_info(self):
        return {
            "name": "file_manager",
            "description": "文件和目录管理工具",
            "keywords": ["文件", "目录", "管理", "file"],
            "usage": self.usage
        }
    
    def get_mcp_definition(self) -> Dict[str, Any]:
        return {
            "name": "file_manager",
            "description": "文件和目录管理工具",
            "inputSchema": {
                "type": "object",
                "properties": {
                    "operation": {
                        "type": "string",
                        "enum": ["list", "read", "write", "delete"],
                        "description": "操作类型"
                    },
                    "path": {"type": "string", "description": "路径"},
                    "content": {"type": "string", "description": "内容"}
                },
                "required": ["operation"]
            }
        }
    
    def convert_mcp_args(self, arguments: Dict[str, Any]) -> str:
        op = arguments.get("operation", "")
        path = arguments.get("path", "")
        content = arguments.get("content", "")
        if content:
            return f'{op} {path} -c "{content}"'
        return f"{op} {path}"
    
    def handle(self, args: str) -> str:
        parts = args.strip().split(maxsplit=2)
        if not parts:
            return "错误：请提供操作类型"
        
        operation = parts[0].lower()
        
        if operation == "list":
            return self._op_list(parts[1:] if len(parts) > 1 else ["."])
        elif operation == "read":
            return self._op_read(parts[1:] if len(parts) > 1 else [])
        elif operation == "write":
            return self._op_write(parts[1:])
        elif operation == "delete":
            return self._op_delete(parts[1:])
        
        return f"错误：不支持的操作 '{operation}'"
    
    def _op_list(self, args: List[str]) -> str:
        path = args[0] if args else "."
        if not os.path.exists(path):
            return f"错误：路径不存在: {path}"
        # 实现列出目录逻辑...
        return f"目录内容: {path}"
    
    def _op_read(self, args: List[str]) -> str:
        if not args:
            return "错误：请提供文件路径"
        # 实现读取文件逻辑...
        return "文件内容..."
    
    def _op_write(self, args: List[str]) -> str:
        if len(args) < 2:
            return "错误：请提供文件路径和内容"
        # 实现写入文件逻辑...
        return "写入成功"
    
    def _op_delete(self, args: List[str]) -> str:
        if not args:
            return "错误：请提供路径"
        # 实现删除逻辑...
        return "删除成功"
```

```python
class MySkill(Skill):

            "type": "function",

                "name": self.name,
                "description": self.description,
                "parameters": {
                    "type": "object",
                    "properties": {
                        "operation": {"type": "string"}
                    }
                }
            }
        }
    
    def run(self, **kwargs) -> SkillResult:
        try:
            operation = kwargs.get("operation", "")

                success=True,
                message="执行成功",

                success=False,
                error=str(e)
```

### 5.2 MCP调用格式

**请求：**
```json
{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
        "name": "file_manager",
        "arguments": {
            "operation": "read",
            "path": "test.txt"
        }
    }
}
```

**响应：**
```json
{
    "jsonrpc": "2.0",
    "id": 1,
    "result": {
        "content": [
            {"type": "text", "text": "文件内容..."}
        ],
        "isError": false
    }
}
```

```json

    "file": "base64_encoded_data",
    "filename": "example.txt",
    "text": "附加说明"
```

## 10. 常见问题

### Q1: 插件不加载？

检查以下几点：
- 文件是否放在 `plugins/` 目录
- 类名是否为 `Plugin`
- 是否实现了 `get_tool_info()` 和 `handle()` 方法
- 文件名是否为 `.py` 结尾

### Q2: 插件不被调用？

检查：
- 关键词是否匹配用户输入
- `keywords` 列表是否正确设置
- 插件是否成功加载（查看启动日志）

### Q3: MCP格式调用失败？

确保：
- 实现了 `get_mcp_definition()` 方法
- 实现了 `convert_mcp_args()` 方法（如果需要）
- `inputSchema` 格式正确

### Q4: 如何调试？

- 在 `handle()` 方法中添加 `print()` 语句
- 检查返回值是否为字符串
- 查看主程序日志

### Q5: 如何处理大文件？

```python
# 限制输出长度
MAX_LENGTH = 10000
if len(content) > MAX_LENGTH:
    content = content[:MAX_LENGTH] + "\n... (内容已截断)"
```
