✨ 本次更新亮点

v5.1.2 新增 3 大功能，补齐了编辑后自动验证和可视化界面的短板。

NEW

自动语法检查

编辑操作完成后自动触发，覆盖 11 种语言：Python (ast.parse + py_compile 双重验证)、JavaScript、TypeScript、JSON、YAML、TOML、HTML/XML、CSS、Shell (bash -n)、SQL。通过显示 ✓，失败显示精确的行号/列号/错误描述。AI 也可主动调用 syntax_check。

NEW

Diff 弹窗

每次编辑后自动弹出新终端窗口，显示修改前/后的完整内容（带行号）、unified diff 差异、+N/-M 行数统计。兼容 Windows (cmd) / macOS (Terminal) / Linux (gnome-terminal 等 6 种)。异步不阻塞，diff_popup on/off 一键开关。

NEW

Web UI

纯静态 HTML 界面，零依赖、零后端，浏览器直接打开。三栏布局：左侧文件树、中间对话/编辑器（Tab 切换）、右侧状态面板。暗色主题、动画效果、快捷芯片、行号编辑器、Ctrl+S 保存。

v5.1.2 新增的独有优势

这三项功能在同类产品中均无直接竞品。

自动语法检查 — 行业空白

Claude Code：不做语法检查，依赖模型自身判断。
Aider：不做语法检查。
Cursor：有 lint 集成但非自动触发。

小狸：编辑后 自动 触发，11 种语言，AST 级精确错误定位。AI 修改代码后立刻知道对不对，不用等运行时才发现。这是编程 CLI 赛道的首创。

Diff 弹窗 — 所见即所得

Claude Code：终端内显示 diff 文本。
Aider：终端内显示 diff。
Cursor：IDE 内置 diff 视图。

小狸：每次编辑后 弹出独立窗口，完整显示修改前后内容 + 行号 + unified diff + 统计。不挤在终端里，一目了然。diff_popup off 一键关闭。

Web UI — 零门槛

Claude Code：纯 CLI，无 UI。
Aider：纯 CLI，无 UI。
OpenClaw：Canvas 组件，非完整 UI。

小狸：纯静态 HTML 文件，双击打开。暗色主题三栏布局，对话 + 编辑器 + 文件树 + 状态面板。不需要 npm、不需要 Flask、不需要任何后端。

SWOT 分析（更新后）

Strengths

  • 自动语法检查 — 行业首创，11 语言，编辑后即时反馈
  • Diff 弹窗 — 独立窗口对比，所见即所得
  • 三模式界面 — CLI + TUI + Web UI，覆盖所有场景
  • 功能密度极高 — 16 插件 142 操作，2 个月一人完成
  • 安全纵深 — AST 沙箱 + 子进程隔离 + 三模式
  • 本地模型原生 — Ollama 开箱即用，完全离线
  • 中文原生 + MIT 开源 — 国内开发者零门槛

Weaknesses

  • 模型能力差距 — 本地模型 vs Claude/GPT-4 鸿沟仍在
  • 单人维护 — 长期迭代速度和可持续性存疑
  • 社区生态空白 — 无插件市场、无活跃贡献者
  • 架构复杂度 — cli_core.py 对话循环待拆分
  • Web UI 是静态 — 无后端，不能真正执行操作

Opportunities

  • 国产替代 — 中文原生 + 本地模型是巨大优势
  • 本地 AI 爆发 — Ollama/llama.cpp 快速发展
  • 语法检查可产品化 — 独立为 CI/CD 工具或 IDE 插件
  • 教育市场 — 免费 + 中文 + 有趣（彩蛋情书）
  • Web UI 可进化 — 加后端即可变为完整 Web IDE

⚠️ Threats

  • 大厂碾压 — Claude Code / Cursor 资金和模型优势
  • 开源竞品 — Aider、Cline、Continue.dev 社区更活跃
  • AI 工具快速迭代 — 功能可能被快速复制
  • 维护可持续性 — 单人项目最大风险

结论

能不能抗衡？

功能维度：能。16 插件 142 操作 + 自动语法检查 + Diff 弹窗 + 三模式界面，功能广度已经超过 Claude Code 和 Aider，在语法验证维度甚至领先全行业。

体验维度：接近。Web UI 补齐了可视化短板，TUI 动画体验独特。但底层模型能力差距决定了对话质量和代码生成精度仍有代差。

生态维度：差距大。社区、插件市场、贡献者体系是最大的结构性劣势。功能做得再好，一个人扛不住长期迭代。

一句话：功能够打，体验能看，生态要追。v5.1.2 是一次关键的能力补齐。
