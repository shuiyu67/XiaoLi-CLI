谁适合用什么？

没有最好的工具，只有最合适的场景。

企业级团队协作

→ Claude Code
  • 子代理机制成熟，支持记忆和分工
  • Bedrock / Vertex AI 企业级部署
  • MCP 协议生态最完善
  • 安全可控，支持 step-by-step 审查

个人开发者 / 开源项目

→ Aider / Gemini CLI
  • Aider：Git 深度集成，多模型自由切换
  • Gemini CLI：免费额度慷慨，1M 上下文
  • 两者都完全开源，社区活跃

本地优先 / 隐私敏感

→ 小狸 Pro-CLI / Aider
  • Ollama 原生支持，数据不出本机
  • 无需 API Key，完全离线可用
  • 适合涉密项目或网络受限环境

国内开发者 / 零成本

→ 小狸 Pro-CLI / TG HELPER
  • 原生支持 DeepSeek / 硅基流动
  • 本地 Ollama 完全免费
  • 无需翻墙，开箱即用

全栈自动化 / 编码为主

→ 小狸 Pro-CLI
  • 唯一内置浏览器自动化的 CLI 工具
  • 15 插件覆盖编码→测试→部署
  • 三界面切换，适合纯编码场景

桌面全能管家 / IoT

→ TG HELPER
  • 物联网控制中心（MQTT/TCP/UDP）
  • QQ 机器人 + 语音合成
  • 办公自动化（Excel/PDF/Word）
  • Arduino 嵌入式全流程
  • 适合需要"操作系统级"控制的场景

社交陪伴 / 多人格

→ TG HELPER
  • 3 种内置人格（暖男/傲娇/中性）
  • "热闹模式"多人格群聊互喷
  • QQ 群聊概率性自动回复
  • 17 种皮肤，个性化极强

AWS / 云原生 DevOps

→ Amazon Q CLI / Copilot CLI
  • 深度集成 AWS 服务和 IAM
  • Copilot CLI：GitHub 生态无缝衔接

国产双雄深度点评

小狸 Pro-CLI vs TG HELPER — 同为国产开源，风格截然不同。

小狸 Pro-CLI

亮点

  • 功能密度极高 — 15 插件 141 操作，一个人干了一个团队的活
  • 安全沙箱 AST 级检测 + 子进程隔离，同类最扎实
  • 三界面覆盖 — CLI + TUI + Web UI
  • 浏览器自动化 — Playwright 31 操作
  • 本地模型原生 — Ollama 零成本起步
  • JSON 解析 7 层 fallback — 被 AI 坑出来的实战经验
  • 113 个测试用例 — 比很多大厂项目覆盖率都高

不足

  • 无 MCP 支持，无法接入大厂工具链
  • 无 IDE 集成，纯终端
  • 社区规模小，单人维护
  • Mixin 架构耦合高
  • 无记忆系统（只有对话历史压缩）
  • 无 IoT / 社交 / 办公自动化能力

TG HELPER

亮点

  • 功能广度碾压 — 70+ 工具覆盖文件/浏览器/IoT/QQ/办公/嵌入式/多媒体
  • 记忆系统业界领先 — 短期+长期+反思+SQLite FTS5+ChromaDB 向量检索
  • 物联网控制中心 — MQTT/TCP/UDP 全协议，主动巡检，传感器触发器
  • QQ 机器人深度整合 — OneBot 协议，群聊陪伴，语音合成
  • 人格系统 — 3 种人格 + "热闹模式"群聊互喷，社交属性拉满
  • 插件 V2 跨平台 — 适配 OpenClaw 和小狸插件，AI 一键转换
  • 反反爬虫 — 随机 UA、假装手抖、代理切换，实战级
  • Arduino 全流程 — 从装 CLI 到烧录板子，一条龙
  • 17 种皮肤 — 从暗黑到粉嫩少女风

不足

  • 代码编辑能力弱 — 没有精准替换、AST 分析、语法检查
  • Windows 为主 — 跨平台支持不如 CLI 工具
  • GUI 依赖 — 没有 CLI 模式，不适合无头服务器
  • 安全机制薄弱 — 无 AI 风险分析，无代码沙箱
  • 版本较早 — v0.1.5，多 Agent 功能仅预留
  • 文档粗糙 — README 风格过于"接地气"
  • 子 Agent 未实现 — multi_agent.py 仅框架

总结

Claude Code 是当前综合最强的 CLI 编程助手，子代理 + MCP + 企业级安全，但价格不菲且闭源。


Aider 是开源社区的标杆，Git 深度集成 + 多模型支持，极客首选。


Gemini CLI 靠免费 + 1M 上下文杀出一条路，适合预算有限的个人开发者。


小狸 Pro-CLI 是"编码特化型" — 一个人做出了大厂级的代码编辑和安全能力，三界面切换、浏览器自动化在同类工具中独一无二。适合以编码为核心的开发者。


TG HELPER 是"桌面全能型" — 功能广度碾压所有竞品，IoT 控制、QQ 机器人、人格系统、记忆系统、Arduino 全流程这些特性在 AI 助手领域前无古人。适合想要一个"真正的生活/工作管家"的用户。


彩蛋：TG HELPER 已经内置了小狸和 OpenClaw 的插件适配器，理论上可以互相导入插件。国产 AI 工具生态正在形成自己的联盟。
